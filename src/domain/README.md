# Domaine Nearly
Types métier dans `models.ts`. Évaluation directionnelle pure dans `compatibility.ts`.
Les paramètres non validés sont isolés dans `src/data/config.ts` et documentés dans `Docs/07-sprint-prototype-local.md`.
Les transitions locales (croisement, cœur, match, message, visibilité, blocage) sont dans `src/services/social.ts`, indépendantes de React. Aucun score public, Bluetooth, santé ou géolocalisation.
