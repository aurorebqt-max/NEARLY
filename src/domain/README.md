# Métier partagé (réservé)
Aucune règle métier n'est implémentée dans la mission 1. Les futurs modules de compatibilité, rencontres et cœurs seront du TypeScript indépendant de React, du DOM et des API natives. Les règles ouvertes restent dans Docs/06-questions-ouvertes.md. Les adaptateurs de stockage, notifications et proximité seront ajoutés uniquement dans une mission autorisée.
